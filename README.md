На данный момент реализованна первая лабараторная работа.
Проект запускается через IDE CLion. Внутри уже зашиты готовые сценарии запуска. Для теста первой лабараторной работы достаточно запустить сценарий "DED OS Realese". 

В результате запуска в папке cmake-build-debug/Binary будут созданы следующие файлы:

*boot.bin* — скомпилированный бинарник самого загрузчика

*kernel.bin* — для первой лабараторной полезная нагрузка, для послежующих ядро

*boot.img* — файл дискеты
